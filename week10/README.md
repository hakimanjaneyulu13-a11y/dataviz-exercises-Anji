# 🌍 CO₂ Emissions Explorer

An interactive **Streamlit dashboard** for exploring and visualizing global CO₂ emissions across countries and years. The application helps users analyze emission trends through dynamic charts, filters, and insightful visualizations.

## 🚀 Live Demo

🔗 https://dataviz-exercises-anji-ipw6sj4cgrcur9rfqyzxvz.streamlit.app/#co-emissions-explorer

---

## 📌 Features

- 🌎 Explore CO₂ emissions by country
- 📅 Filter data by year
- 📊 Interactive visualizations using Plotly
- 🔍 Compare emission trends across multiple countries
- 📈 Analyze historical emission patterns
- ⚡ Fast and responsive Streamlit interface
- 🎨 User-friendly dashboard with interactive filters

---
